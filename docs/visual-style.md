Gaya Visual Kustom — Nyala

1. Konsep Utama
   “Warm Fire, Soft Companion”
   Nyala menggabungkan energi api yang hidup dengan rasa hangat dan dekat seperti teman. Bukan agresif atau terlalu “techy”, tapi terasa modern, suportif, dan membumi. Visual harus memberi kesan “aku nemenin kamu”, bukan “aku menggurui kamu”.

2. Color Palette
   Primary

Fire Orange → #FF5A1F (utama)
Deep Ember → #E04500 (hover / active)

Secondary

Deep Navy → #0F172A (teks utama & elemen kuat)
Soft Navy → #1E293B

Neutral

Warm White → #FAFAF9
Soft Gray → #F1F5F9
Medium Gray → #94A3B8

Accent

Soft Cream → #FFF7ED
Gentle Yellow → #FDBA74 (highlight ringan)

Dark Mode (sangat disarankan)

Background: #0B1120
Card: #1E293B
Text: #F8FAFC
Primary tetap pakai Fire Orange agar tetap “menyala”

3. Typography

Heading: Plus Jakarta Sans / Satoshi / Inter Tight (Bold & SemiBold)
Body: Inter atau Plus Jakarta Sans (Regular & Medium)
Hirarki jelas: Heading besar dan berani, body tetap nyaman dibaca di mobile
Hindari font yang terlalu kaku atau terlalu playful

4. Visual Style & Shape

Corner Radius: Medium-Large (12px–20px) → terasa ramah dan modern
Cards: Soft shadow + subtle border, atau glassmorphism ringan
Buttons: Rounded, solid primary, ada state hover yang jelas (sedikit naik / lebih terang)
Icons: Rounded style (bukan sharp), line + filled combination
Illustration: Semi-flat dengan sedikit depth, karakter yang friendly dan sederhana (bisa pakai gaya outline + fill hangat)

5. Mood & Atmosphere

Terang, bersih, tapi tetap hangat
Banyak ruang napas (generous whitespace)
Micro-interaction halus (Framer Motion): fade, soft scale, progress yang memuaskan
Gradient sangat minimal dan hanya digunakan untuk aksen (misalnya hero atau progress bar)
Hindari tampilan yang terlalu “corporate” atau terlalu “gamey”

6. Komponen Khas Nyala

Progress Bar: Gradient orange yang terasa hidup
Mood Selector: Emoji besar + soft background card
Chat Bubble: Companion pakai warna cream/orange lembut, user pakai navy
Hero Section: Bold typography + tagline yang menonjol + ilustrasi atau abstract fire yang soft
Empty State: Ramah dan encouraging, bukan kaku

7. Referensi Mood (bukan copy)
   Bayangkan gabungan antara:

Energi Duolingo (tapi lebih dewasa)
Kehangatan Headspace
Kebersihan Linear / Notion
Sentuhan api yang lembut ala brand modern Gen-Z

Ringkasan Gaya dalam Satu Kalimat:
Modern, hangat, energetic, dan ramah — seperti api kecil yang menemani, bukan membakar.
